this is project to convert a company website made by statamic CMS to sunrice CMS.
https://github.com/littleboy130491/sunrice-cms

the content should be put in the CMS with similar structure like in statamic cms.
the statamic files exist on 'statamic' folder.
including the forms, site settings, SEO.

success criteria:
- the website is live using sunrice CMS, as close as possible with the original statamic
- all of the contents that come from the statamic CMS, should be migrated to sunrice CMS
- record the problem in the docs called 'FINDINGS.md'
- currently the statamic use gtranslate (Auto translate), we will use sunrice cms translation feature, translate all of the content manually.
